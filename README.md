# Ender IO — Conduits & Machines Mod

[![Download Latest](https://img.shields.io/github/v/release/LastGiraffe98/ender-io-conduits-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/LastGiraffe98/ender-io-conduits-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Multi-layer conduits carry items, fluids, and power in a single block for clean automated bases.

## Features

- Multi-layer conduits combine item, fluid, and power
- Dark Steel, End Steel, and Vibrant Alloy materials
- Soul Binder for binding mob souls into items
- Void Chest and Item Buffer for automation
- Capacitor Banks for storing large RF amounts

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
